# 페이지 공유 기능 조사와 구현

Obsidian Publish는 노트를 웹에 게시하는 별도 유료 호스팅 서비스입니다. 조사 시점의 공식 가격은 연간 결제 기준 사이트당 월 8달러, 월간 결제 기준 월 10달러입니다. [공식 가격](https://obsidian.md/pricing)

공식 흐름은 노트 선택, 게시, 변경분 재게시, 게시 취소입니다. 게시 취소 후 로컬 노트는 유지됩니다. 연결된 노트를 추가하는 작업은 별도 선택입니다. [공식 게시 안내](https://obsidian.md/help/publish/publish)

공식 서비스의 비밀번호는 사이트 전체에 적용되며 개별 노트별 보호는 지원하지 않습니다. [보안과 개인정보 안내](https://obsidian.md/help/publish/security)

복제본에는 현재 노트의 공개 미리보기, 제목·설명·테마, 랜덤한 고정 URL, 명시적 업데이트, 링크 복사·열기, 공유 중지와 게시 목록을 구현했습니다. 파일 이름을 앱에서 변경해도 관리 기록과 기존 공개 URL을 유지합니다. 보관함이 다르면 같은 상대 경로도 별개로 관리합니다.

선택한 본문만 전송하며 YAML 메타데이터, %% 숨김 주석, HTML 주석을 제외합니다. 코드 예시는 보존합니다. publish: false가 설정된 문서는 거부합니다. 연결된 노트나 첨부파일은 자동으로 게시하지 않습니다.

서버는 Sites와 D1을 사용합니다. 공개 읽기와 게시·삭제 권한을 분리했고, 수정 요청에는 기기 키의 Ed25519 서명·시간·일회용 nonce가 필요합니다. 공개 문서에 관리 키를 넣지 않습니다. 원본 HTML은 실행하지 않고 URL 스킴을 제한하며 외부 이미지를 자동으로 불러오지 않습니다. 공개 응답에는 no-store와 noindex를 설정했습니다.

업로드 전에 로컬 관리 ID를 먼저 저장합니다. 응답이 유실돼도 목록에서 해당 링크를 확인하거나 중지할 수 있습니다. 공유 중지 후 이미 다운로드되거나 복사된 내용까지 회수하는 기능은 없습니다.

자동 테스트 총 22개가 통과했습니다. 실서버에서 익명 열람 200, 동일 URL 업데이트 200, 공유 중지 200, 이후 해당 페이지 404와 no-store를 확인했습니다. 기존 사용자 문서를 시험용으로 올리지 않았으며 검증용 합성 문서를 사용했습니다.

사이트 비밀번호, 사용자 지정 도메인, 첨부파일 공개, 보관함 전체 사이트 탐색·검색은 이번 범위에 포함하지 않았습니다. 기존 화면 제어 도구 연결 오류 때문에 자동 시각 검증은 제한됐으며, 빌드·단위 검증·HTTP 검증으로 확인했습니다.

## 서비스 이름

서비스 표시는 옵시온(Obsion)으로 변경했습니다. 기존 공개 링크와 게시 기록, 키, 로컬 보관함 경로는 유지합니다.

이름 변경 후 22개 테스트와 데스크톱 패키징, 공유 서비스 버전 3 배포가 완료됐습니다. 설치된 Obsion 런타임에서 기존 암호화된 공유 키를 실제로 읽을 수 있음을 확인하고, 같은 공개 URL에 사용 안내 문서를 업데이트했습니다. macOS의 .md 기본 앱은 ~/Applications/Obsion.app으로 연결했고 정상 실행을 확인했습니다.
