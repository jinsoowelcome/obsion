# 옵시온 · Obsion

현재 설치된 Obsidian 1.14.5를 REA로 분석하고, 열린 앱 화면을 관찰해 새로 구현한 macOS용 마크다운 작업 공간입니다.

## 실행

이 저장소의 기준 환경은 macOS 12 Intel(x64)입니다. 아래 개발 절차로 소스를 설치한 뒤 `npm run package`를 실행하면 `release/mac/Obsion.app`이 생성됩니다. 생성한 앱을 더블클릭하면 됩니다. 패키징된 앱에는 별도 개발 서버나 원본 Obsidian 앱이 필요하지 않습니다.

새 설치의 기본 노트 폴더는 `~/Documents/Obsion Vault`입니다. 기존 사용자의 보관함과 `Obsidian Replica` 데이터 경로는 계속 사용하므로 노트·설정·공유 링크가 유지됩니다. 처음 생성한 전용 폴더에만 샘플 노트를 넣습니다. 원본 Obsidian 보관함을 자동으로 읽거나 수정하지 않습니다.

## 구현한 기능

- 밝은 테마의 파일 탐색기·편집기·그래프 분할 화면과 크기 조절
- 실제 `.md` 파일 생성·편집·자동 저장·이름 변경, 중첩 폴더
- 실시간 미리보기, 마크다운 원문, 읽기 모드
- `[[노트]]`, `[[노트|표시 이름]]`, 폴더 기준 링크 해석, 백링크
- 연결 그래프, 노드 클릭, 확대·축소·이동·고립 노트 표시
- 전체 내용 검색, 빠른 전환기, 탭, 이전/다음 노트
- 북마크, 일일 노트, 명령어 팔레트, 문서 개요
- 밝은/어두운/시스템 테마, 글꼴 크기, 줄 번호, 읽기 너비
- 네이티브 폴더 선택, 일반 Markdown 보관함 열기
- 노트 한 장의 웹 공유, 공개 전 미리보기, 같은 링크로 업데이트, 공유 중지
- 선택한 파일의 로컬 첨부 공유와 공개 페이지 다운로드
- 4자리 암호로 참여하는 브라우저 공동 편집, 동시 변경 병합과 원본 노트 자동 저장
- 게시한 문서 관리와 링크 복사, YAML·숨김 주석 제외
- `.trash`로 이동하는 복구 가능한 삭제
- 종료 전 저장 대기, 실패한 저장 재시도, 경로·이름 충돌 검사

실시간 미리보기의 링크는 `⌘+클릭`, 읽기 모드의 링크는 클릭으로 엽니다. 외부 편집기로 파일을 바꿨다면 명령어 팔레트에서 **보관함 파일 새로고침**을 실행하세요. 이름을 바꾼 노트를 참조하는 기존 링크는 직접 수정합니다.

## 개발과 검증

macOS 12에서는 Node.js 22.12 이상(22.x)을 사용합니다. Node.js 24의 공식 macOS 바이너리와 Electron 44 이상은 macOS 12를 지원하지 않아 이 저장소는 Electron 43을 사용합니다.

```sh
git clone https://github.com/jinsoowelcome/obsion.git
cd obsion
npm ci
npm run build
npm run desktop
```

브라우저 개발 미리보기는 `npm run dev`로 엽니다. 브라우저에서는 로컬 저장소를 사용하며 네이티브 폴더 선택은 데스크톱 앱에서 사용합니다.

```sh
npm test
npm run package
```

실제 파일 저장과 저장 실패 중 종료·동시 편집, 웹 공유·로컬 첨부·브라우저 공동 편집 등을 다루는 테스트 34개를 통과했습니다. REA로 별도 시험용 보관함의 생성·자동 저장·링크 이동·검색·북마크·테마·이름 변경·명령어·휴지통 동작을 실행했습니다. 분석 근거와 범위는 [분석 보고서](evidence/ANALYSIS.md)에 기록했습니다.

## 범위

Obsidian 공식 앱과 별개의 학습용 구현입니다. 원본 소스와 번들을 복사해 실행하지 않습니다. 커뮤니티 플러그인 실행, Sync, Canvas, Bases, PDF·이미지·수식·Mermaid 렌더러는 포함하지 않습니다. 마크다운 렌더러와 편집기의 세부 동작이 원본과 완전히 같다는 검증은 하지 않았습니다.

보관함당 노트 5,000개, 노트당 8MB, 전체 노트 64MB까지 지원합니다. 외부 편집기의 변경 자동 감시와 충돌 병합은 지원하지 않으며, 브라우저 공동 편집 세션 안의 변경은 자동 병합합니다. macOS 12 Intel(x64)용 로컬 앱이며 배포용 개발자 인증서 서명과 공증은 적용하지 않았습니다.

## 웹 공유

노트 위쪽 공유 아이콘 또는 노트 옵션의 **웹에 공유**를 선택합니다. 제목·설명·테마와 미리보기를 확인한 뒤 **공유 링크 만들기**를 누르면 됩니다. 링크를 아는 사람은 로그인 없이 읽을 수 있고, 앱을 닫아도 페이지가 유지됩니다. 수정 후 **공개 페이지 업데이트**를 눌러 같은 링크에 반영합니다.

**공유한 문서** 목록에서 링크 복사·열기·공유 중지를 할 수 있습니다. 공유 중지는 웹 게시본만 제거합니다. 실제 서버에서 게시·익명 열람·업데이트·중지 후 404 응답을 검증했습니다.

공유 서비스는 독립적으로 구현한 Cloudflare Workers + D1 서비스입니다. Obsidian Publish 계정이나 서버에 접속하지 않습니다. 다른 노트와 첨부파일은 자동 업로드하지 않으며 사이트 비밀번호·사용자 지정 도메인은 포함하지 않습니다. 공개 본문은 200KB까지 지원합니다. 키와 공유 관리 기록은 앱의 userData/publishing에 저장하며, 키는 OS 암호화가 가능한 경우 safeStorage로 보호합니다. 이 폴더를 지우면 공유 관리 정보를 잃을 수 있습니다.

공유 창의 **파일 첨부**에서 파일을 선택한 뒤 공유 링크를 만들거나 공개 페이지를 업데이트하면 다운로드 버튼이 나타납니다. 파일당 5MB, 최대 10개·합계 10MB까지 선택할 수 있습니다. 선택한 파일은 이 PC의 앱 데이터 폴더에 복사해 보관합니다. R2를 사용하지 않으며 파일은 Cloudflare Tunnel을 통해 이 PC에서 전달됩니다. **다운로드할 때 이 PC가 켜져 있고 인터넷에 연결돼 있으며 Obsion 앱이 실행 중이어야 합니다.** 원본 파일을 수정해도 공유 사본은 바뀌지 않으므로 변경된 파일을 다시 첨부해야 합니다. 공유 중지 시 다운로드도 차단되고 로컬 공유 사본을 정리합니다.

서버 소스와 [Cloudflare 연결·배포 절차](publish-service/CLOUDFLARE.md)는 `publish-service/`에 있습니다. 현재 앱은 `https://obsion-publish.jinsoowelcome.workers.dev`에 연결돼 있습니다. 게시와 편집 설정 권한은 등록한 기기의 서명 키로 제한되며, 방문자는 게시자가 공동 편집을 켠 노트에 한해 PIN으로 참여할 수 있습니다. 기존 Sites 링크는 저장된 주소와 기존 키로 계속 관리합니다.

공유 링크를 만든 뒤 공유 창의 **브라우저 공동 편집**에서 숫자 4자리 암호를 입력하고 **공동 편집 켜기**를 누릅니다. 참여자는 링크의 **암호 입력하고 편집**에서 이름과 암호로 참여합니다. 수정은 자동으로 이 PC의 원본 `.md`에 저장되며, 여러 사람의 변경은 CodeMirror 변경 이력으로 병합합니다. 편집 중인 원본은 앱에서 읽기 전용으로 표시합니다. 새 첨부나 공개 제목을 바꾸려면 공동 편집을 먼저 끄고 업데이트하세요.

공동 편집을 켤 때 원본을 앱 데이터의 `publishing/edit-backups/`에 백업하고 YAML 속성은 공개·편집 대상에서 제외해 그대로 보존합니다. 본문에 숨김 주석이 있으면 공동 편집을 켜기 전에 별도 노트로 옮겨야 합니다. 원본이 외부 편집기에서 변경되면 덮어쓰지 않고 편집을 중단합니다. 앱 재시작 후 참여자는 암호로 다시 참여해야 하며, 전송되지 않은 입력은 브라우저 편집기에 유지됩니다. 앱·PC·인터넷이 켜져 있어야 공동 편집을 사용할 수 있습니다.

## 저장소 구성

- [공유 페이지·첨부파일·공동 편집 구현 가이드](docs/앱_공유페이지_첨부파일_공동편집_구현가이드.md): 다른 앱에 같은 구조를 적용하는 방법
- `src/`: 편집기, 그래프, 설정과 공유 화면
- `electron/`: 보관함 파일 처리, 자동 저장 연동, 웹 공유 서명과 macOS 앱 연결
- `publish-service/`: 공개 문서 페이지, 서명 검증 API와 D1 마이그레이션
- `tests/`: 저장, 링크, 초안 복구와 공유 기능 검증
- `evidence/`: 분석 보고서와 시험용 보관함의 화면 캡처

설치 앱, 의존성, 빌드 결과, 개인 보관함, 공유 개인 키와 로컬 분석 원본은 저장소에 포함하지 않습니다. 공개 서비스의 주소와 허용 공개 키는 서버 연결 설정으로 포함됩니다.

## 이름 변경과 호환성

서비스 이름은 **옵시온(Obsion)**입니다. 현재 빌드한 앱은 `release/mac/Obsion.app`이며, 패키징만으로 앱을 다른 위치에 설치하거나 `.md` 기본 앱을 바꾸지는 않습니다. 기존 설치 환경의 `.md` 연결과 사용자 데이터를 이어받을 수 있도록 번들 ID, 브라우저 저장 키, 공유 인증 헤더와 공개 링크 주소를 유지합니다. macOS 공유 키의 암호화를 해제할 수 있도록 Electron의 준비 전 이름은 기존 Keychain 식별자로 유지하고, 준비가 끝나면 앱 이름을 Obsion으로 전환합니다.
